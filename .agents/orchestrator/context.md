# Context Log - Glassmorphic Redesign Project

## Project Goal
Redesign the glass effect on the Kazu Hub website to match Apple's modern macOS/iOS glassmorphism style, ensuring it is subtle, highly performant, and realistic.

## Key Files
- `index.html`: Main HTML containing dashboard structure, Bento cards, loading screens, and custom inline scripts.
- `styles.src.css`: Source CSS containing tokens, Bento grid layout, card gradients, glass panels, spotlight hover effects, and animations.
- `tailwind-input.css`: Main Tailwind input file importing `styles.src.css` and Tailwind directives.
- `styles.css`: Compiled CSS output generated by Tailwind CSS build.
- `features.js`: Custom JS logic for particles, carousel, visualizer, Discord, Steam API integration.
- `js/liquid-glass.js`: Interactive CSS variable mouse tracking engine (specular glow/coordinate updates).
- `tilt-effect.js`: 3D tilt effect on hover for glass elements.

## Constraints
- Keep speed to mph only (Global constraint).
- Hardware-accelerated pure CSS/SVG glass effect.
- Zero performance lag.
- Buttery smooth scrolling and mouse interactions.
- No canvas rendering elements or heavy animation frames in JS for glass effect.
- Genuine frosted glass panels, subtle borders, realistic shadows, no cartoonish liquid specular glares.
