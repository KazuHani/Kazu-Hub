### 🌌 Overview
Welcome to the central repository for the **Kazu Hani Personal Hub Website**. This dashboard acts as a highly personalized, real-time single-page portfolio integrating live status trackers, social platform indexing, multimedia curation, and creative writing projects.

---

### 🚀 Key Features

* **Dynamic Context Engine:** Integrates a 12-hour UK clock, active weather conditions, and an automated age incrementer.
* **Precision Countdown:** A dedicated component counting down days, hours, minutes, and seconds until **November 9th**.
* **Live Presence Sync:** Direct API hooks displaying current activities on **Discord** and **Steam**.
* **Social Matrix Grid:** Modular indexing of profiles across Twitter, Instagram, YouTube, Steam, Reddit, and MyAnimeList (MAL).
* **Media Curation Tray:** Displays active playlists (such as *Songs that SLAP 🐍*) backed by CSS audio visualizers.
* **Creative Writing Dashboard:** Dedicated launchpad for active literary manuscripts.

### 🎨 Design System Specifications

* **Background:** Deep Midnight Blue (`#0B111E`)
* **Accents:** Cyber Cyan, Electric Purple, and Slate Gray
* **Typography:** Geometric sans-serif headers with high-scannability tabular data blocks
* **Layout Structure:** Border-mapped grid interfaces featuring uniform `border-radius` micro-containers
